# Demo app

Put the simple CRUD app we'll use for the hackathon demo here. We haven't chosen its stack or built it yet.

The app needs a real local database and a bug we can reproduce. It must support creating, viewing, editing, and deleting records without cloud authentication, payments, or email.

First, prove that we can run the app, reproduce the bug, and repair it offline on the demo laptop. Use that result to choose the app stack, local model, and coding harness.

Coordinate with whoever builds [verification](../../verification/README.md) so they can check the bug and the saved data. Keep test data separate from the founder's original project.

See [the requirements](../../context/scope-and-tech-requirements.md) for the full demo scope.
